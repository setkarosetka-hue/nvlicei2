# Ліцей 2 — розклад, домашні завдання, заходи

Неофіційний проєкт, не затверджений школою. Усі дані в `index.html` демонстраційні.

## Що є на сайті

- **Розклад** за класами, вчителями та кабінетами (як в UNTIS).
- **Заміни** по днях тижня.
- **Домашні завдання** для обраного класу.
- **Заходи** — найближчі події школи.
- **Відсутні** — вчителі та класи, які відсутні в найближчі дні.

## Як опублікувати на GitHub Pages

1. Створіть репозиторій на GitHub, наприклад `licey2`.
2. Завантажте `index.html` і `README.md` (Add file → Upload files) та збережіть (Commit).
3. Settings → Pages → Source: гілка `main`, папка `/ (root)` → Save.
4. Сайт з’явиться за адресою `https://ВАШ-ЛОГІН.github.io/licey2/`.

## Як змінювати дані

Відкрийте `index.html` на GitHub, натисніть значок олівця (Edit) і знайдіть блок
`ДАНІ: редагуйте тут` на початку скрипта. Там три списки:

- `HW` — домашні завдання: `{d:'2026-11-09', c:'7А', k:'mat', t:'Текст завдання'}`
  (`k` — предмет: `mat`, `rus`, `lit`, `eng`, `phy`, `chem`, `bio`, `his`, `geo`, `inf`, `pe`, `soc`)
- `EV` — заходи: `{d:'2026-11-12', tm:'14:00', t:'Назва', pl:'Місце', c:'Для кого'}`
- `AB` — відсутні: `{d:'2026-11-09', w:'Прізвище або клас', ty:'Вчитель', n:'Примітка'}`

Минулі дати на сайті не показуються. Після змін натисніть «Commit changes», сайт оновиться за хвилину.

## Конфіденційність

Не публікуйте прізвища учнів і медичні причини відсутності. Для відсутніх використовуйте нейтральні примітки.
