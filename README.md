# 🏫 Ліцей №2 — Електронна система

Сучасна вебсистема для організації навчального процесу ліцею.

> ⚠️ **Важливо:** на даний момент система перебуває у розробці та тестуванні. Вона **не є офіційно підтвердженою або затвердженою адміністрацією школи**, доки таке підтвердження не буде отримано.

# 👥 Ролі користувачів

Система передбачає чотири основні ролі:

### 👨‍💼 Адміністратор

Керує користувачами, системою, налаштуваннями та навчальними даними.

### 👨‍🏫 Учитель

Має доступ до розкладу, домашніх завдань, оцінок, тестів та відвідуваності.

### 🎓 Учень

Може переглядати розклад, домашні завдання, оцінки, тести, події та повідомлення.

### 👨‍👩‍👧 Батьки

Можуть переглядати інформацію про навчання своєї дитини.

---

# 📋 Правила та згода

Перед першим використанням системи користувач повинен ознайомитися з правилами.

На сторінці `consent.html` передбачені:

* 📜 повний список правил;
* 🔒 обов'язкові правила;
* ⚙️ налаштування необов'язкових дозволів;
* ✅ «Погодитися з усіма»;
* ✅ «Погодитися лише з обов'язковими»;
* ⚙️ «Налаштувати».

Обов'язкові правила не можна вимкнути.

Після підтвердження згода зберігається, щоб користувачу не потрібно було підтверджувати її при кожному вході.
